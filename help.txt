UWD2 v{}

USAGE:
    {} [SUBCOMMAND]

SUBCOMMANDS:
    <no subcommand>  Alias for patch
    patch            Apply the watermark patch to the running explorer.exe
    install          Copy UWD2 to AppData, create startup task, and apply patch immediately
    uninstall        Remove the startup task and installed files
    status           Show whether the startup task is installed and enabled
    repair           Re-create task and re-apply patch (fixes broken installs)
    help             Show this menu
    about            Show information about UWD2

NOTE: UWD2 does NOT remove the "Activate Windows" watermark.
